Make this book your own

Turn pages: use Previous / Next, the left and right arrow keys, or type a page number and press Enter. Arrow keys still operate sliders and text fields normally.

Find an idea: Contents searches all the page text, not just headings. A page address ending in #page-name opens that page directly.

Learn, do not rush: the first 72 pages form the main route. Six optional algebra pages then expose further details; the final two pages answer common questions and list sources.

Progress: Understood is your own judgement. Checkpoint totals count questions whose latest answer is correct. All questions allow retries. Nothing is locked.

Offline: there are no external scripts, fonts, analytics, accounts or background requests. Notes, answers and reading position use local browser storage where available. Export important notes; browsers may remove stored data or treat a renamed file as a different location.

Equations: native MathML displays the mathematical notation. Use a modern browser with MathML support. On a narrow screen, long equations scroll horizontally inside their own box.

Scope: this is an educational explanation of the standard high-Re k–ε model, not a validated engineering-design tool. The demonstrations are not a general CFD solver.

Printing includes written explanations and checkpoint answers. Interactive demonstrations remain in this HTML file.
